# Bounce-In!

Bounce-In! is an arcade video game that mixes the air hockey and pinball mechanics in a strategic 1v1 by turns. Try it with friends!



# About the project

Bounce-In! is a video game that comes from an academic project for a 2D Design subject at the USJ (Universidad de San Jorge).
Each player has 3 disks and the objective is to score them in the rival goal. However, you gotta be careful or you can score on your
own goal. The game loop is clear: you select the direction the disks will go, select the strength for each disk and when all disks are
ready (or the timer ends) these will move.

# Controls

To move around the menus use WASD or the arrows. To select an option use Enter, H or J
To use the disks each player has 3 keys:



| Player | Disk 1 | Disk 2 | Disk 3 |

| --- | --- | --- | --- |

| Player 1 | R | T | Y |

| Player 2 | U | I | O |



Each key selects and shoots its corresponding disk.
